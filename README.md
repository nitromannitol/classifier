# classifier

Two Python scripts that classify test failures as product errors or automation errors. Their
input is a directory of XML files, one per failed test, as generated by
[testng-plugin-modification](https://github.com/nitromannitol/testng-plugin-modification).
Each file contains the elements `Type` (`true` for a product error, `false` for an automation
error), `Duration`, `ErrorS` (the stack trace) and `ErrorM` (the error message). The features
are the duration and the occurrences of each word of the stack trace and the message, where
the words are obtained by splitting on whitespace or on a regular expression given at the
prompt.

- [`analyze.py`](analyze.py) is a Gaussian naive Bayes classifier written from scratch. It
  trains on all the files and reports the accuracy averaged over randomly chosen test subsets
  of the same data.
- [`analyze2.py`](analyze2.py) trains the models of the `mlpy` library on the first tenth of
  the samples and reports their accuracy on the rest: perceptron, elastic net, LibLinear
  support vector machine, DLDA, Golub, Parzen, k-nearest neighbours (`k = 2`), classification
  tree and a maximum likelihood classifier. It uses `mlpy`, described in

  > D. Albanese, R. Visintainer, S. Merler, S. Riccadonna, G. Jurman, C. Furlanello,
  > *mlpy: Machine Learning Python*, 2012;
  > [arXiv:1202.6548](https://arxiv.org/abs/1202.6548).

## Running

Both scripts are written for Python 2 (they use `print` statements, `raw_input`, `xrange` and
`reduce`), which is no longer supported, and they do not run under Python 3 as they are.
`analyze.py` needs only the standard library. `analyze2.py` also needs `NumPy` and `mlpy`,
which is no longer maintained and has to be compiled; its build requirements are GCC, Python
2.6 or later, NumPy 1.3.0 or later (with header files), SciPy 0.7.0 or later and GSL 1.11 or
later (with header files), on GNU/Linux, OS X and FreeBSD.

Each script asks for three things at the prompt (the second script only for the first two):
the directory that contains the XML files, how to split the words (a blank line splits on
whitespace), and, for `analyze.py`, how many random test subsets to average over.

```
python2 analyze.py
python2 analyze2.py
```
